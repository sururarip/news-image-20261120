A magazine-style front page summing up Friday 20 November 2026 in six stories: the Trump–Xi–Putin peace declaration from the Shenzhen summit, Houthi missiles hitting Riyadh's PIF tower and tankers burning off Hormuz, Anthropic's record $81bn IPO debut, the Coalition of the Willing backing Kyiv in Berlin, the COP31 draft dropping fossil fuels and its $120bn figure on its closing day in Antalya, and a markets rout with the Nikkei down 4.5% — plus a ticker on Trump deferring any new Iran strikes to next year. Every fact was checked against reporting dated 20 November 2026 (Reuters, AFP, AP, BusinessWorld). The image is drawn from scratch with geometric illustration only — no faces, no photographs — and `main.py` (Python standard library only) copies it to the output directory.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
